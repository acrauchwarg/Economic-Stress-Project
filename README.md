# Global Economic Stress Analysis Project

## Project Overview
This project analyzes economic stress across countries using data from the World Bank and FAOSTAT.

## What I Did
1. Loaded data from 4 CSV files
2. Cleaned missing values
3. Created new features (ratios, growth rates, interactions)
4. Merged with country metadata
5. Created summaries and saved processed data

## Files Created
- processed_data/merged_data_full.csv - Main dataset
- processed_data/country_summary.csv - Country averages
- processed_data/yearly_summary.csv - Yearly trends
- processed_data/correlation_matrix.csv - Variable relationships
- processed_data/data_dictionary.csv - Column descriptions

## Next Steps
- Exploratory Data Analysis (visualizations)
- Clustering Analysis (find country groups)
- Classification Modeling (predict stress)
- Association Rule Mining (find patterns)
